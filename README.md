# Análise de Desempenho e Demografia de Estudantes do Ensino Médio

### Como rodar isso na sua máquina

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
